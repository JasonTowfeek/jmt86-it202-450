## Project Name: Jason's Meal Project

### Project Summary:

A meal management web application where users can register, log in, browse meals, save meals to their account, remove saved meals, and view public user profiles. Admin users can manage meals, view user-meal associations, assign meals to users, remove associations, and view unassociated meals. The project uses PHP, PostgreSQL, sessions, role-based access, and TheMealDB API.
